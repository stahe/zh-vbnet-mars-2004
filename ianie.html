    1. 简介

    本文档中的 PDF 已发布 |HERE|。

    VB.NET 是一种新兴语言。自 2000 年起，该语言便以测试版形式发布，随后于 2002 年 2 月与相关的 Microsoft .NET 平台一同正式发布。 VB.NET 只能在此运行环境中工作，目前该环境仅适用于 Windows NT、2000 和 XP 系统。

    随着 .NET 平台的推出，出现了三种新语言：C#、VB.VET 和 JSCRIPT.NET。 C#在很大程度上是Java的“复制品”。VB.NET和JSCRIPT.NET是.NET平台上Visual Basic和JScript的扩展。 该平台为其内部运行的程序提供了一套非常重要的类，这些类与Java虚拟机中的类非常相似。粗略地说，.NET平台是一个类似于Java虚拟机的运行环境。但需要注意两点重要区别：

    • .NET 平台仅在 Windows 机器上运行，而 Java 则可在多种 OS 系统（Windows、Unix、Macintosh）上运行。
    • .NET 平台支持运行用不同语言编写的程序。只要这些语言的编译器能够生成 IL（中间语言）代码，该代码即可由 .NET 虚拟机执行。 所有 .NET 类均可供兼容 .NET 的语言使用，这在很大程度上消除了语言间的差异，因为程序广泛使用这些类。选择哪种 .NET 语言更多是个人偏好问题，而非性能考量。

    正如无法忽视 Java 一样，.NET 平台也同样不容忽视，这既源于庞大的 Windows 设备安装基数，也得益于微软在推广和普及该平台方面所做的努力。 鉴于这两种语言的相似性，C#似乎是入门.NET的理想选择，特别是对于Java程序员而言。之后，开发者可以轻松地从C#过渡到VB.NET或其他.NET语言。 虽然语法会发生变化，但 .NET 类将保持不变。与表面印象相反，从 VB 过渡到 VB.NET 其实颇具难度。 VB 并非面向对象的语言，而 VB.NET 则完全是面向对象的。因此，VB 程序员将面临一些他们尚未掌握的概念。 若能抛开对 VB 的既有认知，应对这些概念似乎会更简单。因此，下文中我们将很少提及 VB。

    本文并非详尽的教程。它面向已具备编程基础并希望了解 VB.NET 的读者。本文沿用了同一位作者撰写的《C# 语言入门》一文的结构，以便于两门语言之间的对比。 实际上，我在此使用了C#到VB.NET的自动翻译工具。虽然这些工具并非完全完美，但在不同情况下仍能完成80%至100%的工作。 因此，在阅读下文中的VB.NET程序代码时，请注意这些代码最初是由机器生成的，随后由我根据需要进行了修改。因此，其中可能会出现一些您自己可能不会采用的编程“表达方式”。

    以下书籍对我有所帮助：

    • 《专业C#编程》，Wrox出版社
    • 《C#与.NET》，Gérard Leblanc 著，Eyrolles出版社

    这两本都是非常优秀的著作，我推荐大家阅读。C#程序转换为VB.NET的代码是通过以下网址提供的转换工具生成的 （2004年3月）http://authors.aspalliance.com/aldotnet/examples/translate.aspx。其余内容均来自Visual studio.NET的文档。

    2.2.3. 数据声明

    2.2.3.1. 声明的作用

    程序处理的数据由名称和类型来标识。这些数据存储在内存中。在程序编译时，编译器会根据程序员的声明，为每项数据分配一个由地址和大小标识的内存位置。 此外，这些声明还使编译器能够检测编程错误。例如，如果 x 是一个字符串，则运算 x=x*2 将被判定为错误。

    2.2.3.2. 常量的声明

    常量的声明语法如下：

    const 标识符 as 类型=值

    例如 [const PI as double=3.141592]。为何要声明常量？

    1. 如果为常量赋予一个有意义的名称，程序将更易于阅读：[const taux_tva as single=0.186F]
    2. 如果“常量”发生变化，修改程序也会更加容易。因此，在前面的例子中，如果增值税税率变为 33%，唯一需要修改的就是定义其值的语句：[const taux_tva as single=0.336F]。 如果程序中直接使用了0.186，那么就需要修改大量语句。

    2.2.3.3. 变量声明

    变量通过名称进行标识，并关联到一种数据类型。VB.NET 不区分大小写。因此，变量 FIN 和 fin 是相同的。变量可以在声明时进行初始化。声明一个或多个变量的语法为：

    dim 变量1,变量2,...,变量n as 类型标识符

    其中 identificateur_de_type 是一个预定义类型或由程序员定义的类型。

    2.2.5. 数据数组

    数组 VB.NET 是一种对象，用于将同类型的数据集合在同一个标识符下。其声明如下：

    Dim Tableau(n) as type 或 Dim Tableau() as type = New type(n) {}

    其中 n 是数组最后一个元素的索引。语法 Tableau(i) 表示编号为 i 的数据，其中 i 属于区间 [0,n]。 任何引用数据 Tableau(i) 的操作，若 i 不属于区间 [0,n]，都将引发异常。数组可以在声明时同时进行初始化。 在这种情况下，无需指定最后一个元素的编号。

    
        Dim entiers() As Integer = {0, 10, 20, 30}

    区分

    1 由计算机执行的基本指令。

    2 控制程序运行的指令。

    当我们考察微型计算机及其外围设备的结构时，基本指令便显而易见。

    1. 读取来自键盘的信息

    2. 信息处理

    3. 将信息写入屏幕

    4. 从磁盘文件读取信息

    5. 将信息写入磁盘文件

    2.3.1. 屏幕书写

    屏幕上存在多种书写指令：

    Console.Out.WriteLine(expression)
Console.WriteLine(expression)
Console.Error.WriteLine (expression)

    其中 expression 代表任何可转换为字符串并在屏幕上显示的数据类型。在迄今为止的示例中，我们仅使用了 Console.Out.WriteLine(表达式) 语句。

    类 System.Console 提供了屏幕写入操作（Write，WriteLine）。类 Console 具有两个属性 Out 和 Error，它们是类型为 StreamWriter 的写入流：

    • Console.WriteLine() 与 Console.Out.WriteLine() 功能等同，并向通常与屏幕关联的 Out 流写入数据。
    • Console.Error.WriteLine() 写入 Error 流，该流通常也关联到屏幕。

    Out 和 Error 流默认关联到屏幕。但正如我们稍后将看到的，它们可以在程序运行时重定向到文本文件。

    2.3.2. 读取键盘输入的数据

    来自键盘的数据流由类型为 StreamReader 的对象 Console.In 表示。此类对象可通过 ReadLine 方法读取一行文本：

    
        Dim ligne As String = Console.In.ReadLine()

    键盘输入的行被存储在变量 ligne 中，随后可由 programme.Le 进行处理。In 流可像 Out 和 Error 流一样重定向到文件中。

    2.3.4. I/O重定向

    在 DOS/Windows 系统中，有三个标准设备，分别称为：

    1. 标准输入设备——默认指键盘，编号为 0
    2. 标准输出设备——默认指向屏幕，编号为 1
    3. 标准错误设备——默认指向屏幕，编号为 2

    在 VB.NET 中， 写入流 Console.Out 写入设备 1，写入流 Console.Error 写入设备 2，而读取流 Console.In 则从设备 0 读取数据。 在 Windows 的 DOS 窗口中运行程序时，可以指定该程序所使用的设备 0、1 和 2。请看以下命令行：

    pg arg1 arg2 .. argn

    在程序 pg 的参数 argi 之后，可以将标准 I/O 设备重定向到文件：

    0<in.txt
    标准输入流 0 被重定向到文件 in.txt。因此，在程序中，流 Console.In 将从文件 in.txt 中获取数据。
    		  
    1>out.txt
    将输出流 1 重定向至文件 out.txt。这导致在程序中，数据流 Console.Out 会将数据写入文件 out.txt
    		   
    1>>out.txt
    同上，但写入的数据将添加到文件 out.txt 的当前内容中。
    		   
    2>error.txt
    将输出流 2 重定向至文件 error.txt。这将导致程序中的数据流 Console.Error 将其数据写入文件 error.txt
    		   
    2>>error.txt
    同上，但写入的数据将追加到文件 error.txt 的现有内容中。
    		   
    1>out.txt 2>error.txt
    设备 1 和 2 均被重定向到文件

    2.9. 枚举

    枚举是一种数据类型，其取值范围是一组整数常量。假设有一个程序需要处理考试成绩。共有五种成绩：及格、AssezBien、良好、TrèsBien、优秀。因此，我们可以为这五个常量定义一个枚举：

    
    Enum mention
        Passable
        AssezBien
        Bien
        TrésBien
        Excellent
    End Enum

    在内部，这五个常量由连续的整数编码，第一个常量从 0 开始，第二个从 1 开始，依此类推。可以声明一个变量来取枚举中的这些值：

    
        ' 从枚举中获取值的变量
        Dim maMention As mention = mention.Passable

    可以将变量与枚举中的各种可能值进行比较：

    
        ' 使用枚举值进行测试
        If (maMention = mention.Passable) Then
            Console.Out.WriteLine("Peut mieux faire")
        End If

    可以获取枚举的所有值：

    
        For Each m In mention.GetValues(maMention.GetType)
            Console.Out.WriteLine(m)
        Next

    正如简单类型 Integer 等同于结构 Int32 一样，简单类型 Enum 也等同于结构 Enum。 该类有一个静态方法 GetValues，用于获取作为参数传递的枚举类型的所有值。该参数必须是 Type 类型的对象，Type 是一个关于数据类型的信息类。 变量 v 的类型可通过 v.GetType() 获取。 因此，此处 maMention.GetType() 返回枚举 mentions 的对象 Type，而 Enum.GetValues（maMention.GetType()）则返回枚举 mentions 的值列表。

    2.10. 异常处理

    许多 VB.NET 函数可能会引发异常，即错误。当某个函数可能引发异常时，程序员应进行异常处理，以使程序更具容错性：必须始终避免应用程序发生“无预兆的崩溃”。

    异常处理遵循以下流程：

    try
    appel de la fonction susceptible de générer l'exception
catch  e as Exception e)
    traiter l'exception e
end try
instruction suivante

    如果该函数未抛出异常，则跳转至下一条指令；否则，进入子句 catch 的主体，然后跳转至下一条指令。请注意以下几点：

    • e 是 Exception 类型的派生对象。通过使用 IOException、SystemException 等类型可以更精确地指定：存在多种类型的异常。 编写 catch e as Exception 表示希望处理所有类型的异常。如果 try 子句的代码可能引发多种类型的异常，则可以通过使用多个 catch 子句来更精确地处理异常： 
    try
    appel de la fonction susceptible de générer l'exception
catch e as IOException 
    traiter l'exception e
catch  e as SystemException
    traiter l'exception e
end try
instruction suivante
    • 可以在 try/catch 子句中添加一个 finally 子句： 
    try
    appel de la fonction susceptible de générer l'exception
catch  e as Exception
    traiter l'exception e
finally
    code exécuté après try ou catch
end try
instruction suivante

    无论是否发生异常，子句 finally 的代码都会被执行。

    • 在子句 catch 中，可能不希望使用可用的对象 Exception。因此，与其编写 catch e as Exception，不如直接编写 catch。
    • 类 Exception 具有一个名为 Message 的属性，该属性包含详细描述所发生错误的消息。因此，若要显示该消息，应编写如下代码： 
    catch e as Exception
    Console.Error.WriteLine("L'erreur suivante s'est produite : "+e.Message);
    ...
end try
    • 类 Exception 包含一个方法 ToString，该方法返回一个字符串，其中包含异常类型以及属性 Message 的值。因此，我们可以这样编写： 
    catch  ex as Exception
    Console.Error.WriteLine("L'erreur suivante s'est produite : "+ex.ToString)
    ...
end try

      Catch
        Console.Error.WriteLine("Age incorrect, recommencez...")
      End Try
    Loop

        ' 最终显示
    Console.Out.WriteLine("Vous vous appelez [" & nom & "] et vous avez [" & age & "] ans")
  End Sub
End Module

    2.11. 向函数传递参数

    这里我们关注函数参数的传递方式。考虑以下函数：

    
    Sub changeInt(ByVal a As Integer)
        a = 30
        Console.Out.WriteLine(("Paramètre formel a=" & a))
    End Sub

    在函数定义中，a被称为形式参数。 它仅用于定义函数 changeInt。它同样可以命名为 b。现在让我们来看一下该函数的使用示例：

    
    Sub Main()
        Dim age As Integer = 20
        changeInt(age)
        Console.Out.WriteLine(("Paramètre effectif age=" & age))
    End Sub

    在此 changeInt(age) 语句中，age 是将值传递给形式参数 a 的实际参数。 我们关注的是形式参数如何获取与其对应的有效参数的值。

    2.11.1. 按值传递

    以下示例表明，函数/过程的参数默认采用值传递：即实际参数的值会被复制到对应的形式参数中。二者是两个独立的实体。如果函数修改了形式参数，实际参数则完全不受影响。

    
' 选项
Option Explicit On 
Option Strict On

' 按值向函数传递参数
Imports System

Module param1
    Sub Main()
        Dim age As Integer = 20
        changeInt(age)
        Console.Out.WriteLine(("Paramètre effectif age=" & age))
    End Sub

    Sub changeInt(ByVal a As Integer)
        a = 30
        Console.Out.WriteLine(("Paramètre formel a=" & a))
    End Sub
End Module

    所得结果如下：

    Paramètre formel a=30
Paramètre effectif age=20

    实际参数的值 20 被复制到了形式参数中 a。随后该形式参数被修改，而实际参数保持不变。这种传递方式适用于函数的输入参数。

    2.11.2. 按引用传递

    在引用传递中，实际参数和形式参数是同一个实体。如果函数修改了形式参数，实际参数也会随之改变。在 VB.NET 中，形式参数前必须加上关键字 ByRef。以下是一个示例：

    
' 选项
Option Explicit On 
Option Strict On

' 向函数传递按值传递的参数
Imports System

Module param2
    Sub Main()
        Dim age As Integer = 20
        changeInt(age)
        Console.Out.WriteLine(("Paramètre effectif age=" & age))
    End Sub

    Sub changeInt(ByRef a As Integer)
        a = 30
        Console.Out.WriteLine(("Paramètre formel a=" & a))
    End Sub
End Module

    以及执行结果：

    Paramètre formel a=30
Paramètre effectif age=30

    实际参数已跟随形式参数的修改。这种传递方式适用于函数的输出参数。
